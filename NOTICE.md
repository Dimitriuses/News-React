# Notices

The MIT licence in `LICENSE` covers the code in this repository. This file records
everything in it that came from somewhere else, and what happened to it.

Nothing is appended to `LICENSE` itself, deliberately: GitHub's licence detector only
recognises a licence file that is *exactly* the licence text, and reports `NOASSERTION`
for one with notes added after it.

## Images: generated here

The nine SVGs in `public/news/` are generated by `tools/build-snapshot.js` from the
publisher name on each headline. They contain no third-party artwork — just a gradient,
some rounded rectangles and a text label — and are covered by this repository's MIT
licence.

**They replace hotlinks, not files.** The 2019 seed articles carried `image` URLs pointing
at photographs on twelve news publishers' own CDNs (`cdn.cnn.com`, `ichef.bbci.co.uk`,
`media.npr.org`, `imagez.tmz.com`, and so on). Those photographs were never part of this
repository and there was never any grant to redistribute them; a public repository plus a
GitHub Pages demo would have made this project depend on twelve third parties' bandwidth
for its entire appearance. Three of the twelve no longer resolve in any case (checked
2026-07-30: one `406`, two on a host that no longer answers).

## Text: the twelve headlines

`src/newsSnapshot.js` reproduces twelve headlines and their one-sentence summaries as
returned by [newsapi.org](https://newsapi.org) on 26 September 2019 and pasted by hand into
`App.js` at the time. They originate with the publishers named on each card — CNN, BBC
News, USA TODAY, NPR, Fox News, TMZ, CNBC, CNET and CBS News — and every card links to the
publisher's own page. They are kept because they are what this project was actually built
against, and because a demo needs data that cannot rot.

## Credentials

`src/APIClient.js` carried a hardcoded `newsapi.org` API key from 2019-09-30. It has been
removed from the working tree. **It has not been revoked** — the account was registered to
an email address that is no longer reachable and newsapi.org does not recognise it, so
there is no way to log in and disable the key. See the README for the full account.

It is still present in the repository's history and in the `v0.1-original` tag, and that is
deliberate: rewriting history would not undo the years the key was public, and it would
destroy the preserved original.
